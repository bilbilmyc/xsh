# XSH 使用体验优化记录

日期：2026-10-23。对应本轮使用体验评审中的八项问题。

后续已完成 0.1.24 的本地构建、覆盖安装及原生验收，详见 [0.1.24 安装验收记录](local-build-validation-0.1.24-2026-10-23.md)。

本轮结合终端、AI、传输及 Rust 改进完成交互调整，已通过前端构建、自动化测试、隔离浏览器复核和 0.1.24 安装版验收。

## 已完成的行为

| 问题 | 调整后的行为 |
| --- | --- |
| SFTP 连接失败后无法原地恢复 | 显示独立的文件连接状态；连接失败可直接重新连接，目录读取失败可重新读取或重新连接；重连保留当前远程目录。 |
| 文件双栏挤压终端 | 展开为完整文件工作区，提供“返回终端”；底层终端保持挂载和尺寸，展开期间禁止其获得键盘焦点；展开状态不再显示无效的宽度拖动柄。 |
| 本地、远程文件选择不一致 | 两侧共用单击、Ctrl / Command 多选和 Shift 连选规则；本地支持混合选择文件和目录，递归上传、合并目录、保留空目录；全部冲突处理完成前不创建目录、不提交文件。 |
| 字号放大后文字仍过小或布局溢出 | 文件、AI、传输相关辅助文字改用全局字号变量；输入框随字号增高；小窗口缩减重复信息占用的高度，窄文件区同步收起修改时间及表头；列表内部滚动，保留上传按钮和目录摘要。 |
| 弹窗键盘焦点不受约束 | 统一限制 Tab / Shift+Tab 的范围；嵌套弹窗只允许顶层获得焦点；关闭后恢复父弹窗或触发控件的焦点，并补全缺失的对话框语义。 |
| AI 首屏说明挤占输入区域 | 精简任务说明，将示例折叠到输入框之后；预览发送入口保持可达，1366×768 首屏可见输入框及操作按钮。 |
| 关闭文件面板后看不到后台传输 | 工作区状态栏显示后台任务数量、传输速度和失败数；点击失败数直接进入传输管理器的失败筛选。 |
| 新对话或服务变更导致旧内容消失 | 每个终端标签在内存中保留最近 3 份、合计最多 512 KiB 文本的只读旧对话，可展开和复制；归档不进入后续请求历史，不提供命令执行按钮。关闭终端标签或退出程序会清除记录。 |

目录上传跳过本地符号链接和特殊文件。旧对话中单条问题、上下文和回复分别有大小限制，截断保留 UTF-8 边界并显示提示。

Rust 测试使用项目 Windows 构建脚本已有的 `AWS_LC_SYS_PREBUILT_NASM=1` 设置。首次直接运行因本机 NASM 路径未配置而失败，设置当前进程环境后重跑成功，没有安装或修改系统工具。

前端构建仍有现有终端资源包大于 500 kB 的提示，未影响构建完成。

浏览器复核使用当前源码和 Tauri 官方 mock，在独立浏览器会话中提供模拟的 SSH、SFTP、AI 和传输数据；没有连接真实服务器或调用真实模型。覆盖的重点包括：

- 首次连接失败后的重连、目录读取重试，以及连续重连失败后保留远程目录。
- 1366px、1100px、960px 窗口的文件工作区与返回终端行为。
- 960×640、20px 界面字号下，上传按钮和目录摘要完整可见，两侧列表具有滚动空间，文件名与大小不重叠。
- 文件和目录混合选择、递归上传、空目录，以及冲突确认完成前没有创建目录或上传文件。
- 嵌套弹窗焦点限制、父弹窗焦点恢复及关闭后的触发控件恢复。
- AI 首屏输入、旧对话查看、服务变更后的归档，以及归档内容不会加入新请求。
- 后台失败提示和失败任务筛选入口。

后续安装版验收补充了真实 Tauri IPC、Rust SSH / SFTP、环回 Git Bash 及本机 AI 流式服务，范围与限制见上述安装验收记录。
